# Fake News Detection (Mini Project)

## Description

This project uses Machine Learning to classify news as **Fake** or **Real** based on text data.

## Technologies

* Python
* Scikit-learn
* NLP
* Google Colab

## How to Run

1. Open the notebook in Google Colab
2. Run all cells
3. Enter news text for prediction

## Output

* Fake or Real news classification
